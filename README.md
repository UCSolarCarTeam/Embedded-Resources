# Embedded Recruit Training

This repository contains the learning materials and exercises needed to onboard new members and develop their embedded systems skills.

## Sections

### 1. Basic - C Programming

C fundamentals, including data types, functions, pointers, memory, and bitwise operations.

### 2. Intermediate — Embedded Systems

Embedded development with STM32, focusing on peripheral configuration and usage, including GPIO, timers, ADC, UART, I2C, SPI, and CAN.

### 3. Advanced — RTOS

Real-time operating systems, focusing on FreeRTOS, task scheduling, inter-task communication, synchronization, and multitasking.
